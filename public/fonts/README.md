# Licensed fonts

Nexa Regular and SangBleu Regular are commercial fonts, so the files are not in this repo.
Add your licensed web font files here with these exact names:

- `Nexa-Regular.woff2` (body text, option "nexa")
- `SangBleu-Regular.woff2` (the PantriFul wordmark)

Until they are added the site falls back to a system sans-serif for Nexa and Georgia for SangBleu.
Montserrat is bundled through `@fontsource/montserrat`, so option "montserrat" works out of the box.

Try the two options with `/?font=nexa` and `/?font=montserrat`.
